# SQL_Spotify_Music_Analysis
SQL practice with the use of 2 datasets provided from Kaggle (website below):
  \n https://www.kaggle.com/datasets/solomonameh/spotify-music-dataset?select=high_popularity_spotify_data.csv
  \n https://www.kaggle.com/datasets/solomonameh/spotify-music-dataset?select=low_popularity_spotify_data.csv
  It will:
- analyze the popularity of song titles
- provide comparisons amongst different title tracks
- track the popularity of different genres
